# Nitmit IKT

A single-page education-only knowledge terminal for India reference modules, exam routes, official sources, and calculators.

## Included
- Verified official source registry
- Modules and facts library
- Exam and route catalog
- Source/QA views
- Working calculators for growth, SIP, EMI, inflation, and percentage change
- Import/export support for module JSON

## Run locally
Open `index.html` in a browser.

## Notes
- Education only, not investment advice.
- Live market/securities section intentionally excluded to avoid stale-data risk.
